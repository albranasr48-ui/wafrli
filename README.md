# موقع وفرلي WAFRLI

موقع عربي متجاوب (RTL) مبني باستخدام HTML وCSS وJavaScript، ومهيأ للنشر على GitHub Pages.

## الملفات
- `index.html` — أقسام الموقع ونماذج التسجيل.
- `style.css` — التصميم المتجاوب والألوان والحركات.
- `script.js` — القائمة الجانبية، التحقق من النماذج، وتجهيز رسائل واتساب.
- `images/logo.png` — شعار وفرلي المرفق.

## تشغيل الموقع محليًا
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. ارفع جميع الملفات والمجلد `images` إلى المستودع نفسه.
2. من Settings ثم Pages اختر النشر من الفرع `main` والمجلد `/ (root)`.
3. احفظ الإعدادات وانتظر رابط GitHub Pages.

## واتساب
رقم الإدارة مضبوط في أعلى `script.js` في المتغير `ADMIN_PHONE`.
الرقم الحالي `0927772012`، ويقوم الكود بتحويله إلى صيغة ليبيا الدولية `218927772012` داخل رابط واتساب.
بعد تعبئة النموذج، يفتح الموقع رسالة جاهزة؛ يجب على المستخدم الضغط على إرسال في واتساب.

## ملاحظات
- GitHub Pages استضافة ثابتة ولا تحفظ طلبات النماذج في قاعدة بيانات.
- إرسال واتساب لا يحدث تلقائيًا في الخلفية؛ يتطلب فتح واتساب وضغط المستخدم على إرسال.
- تحقق من أن رقم الإدارة المسجل عليه واتساب هو الرقم الصحيح قبل النشر.
- خط Cairo يُحمّل من Google Fonts عند توفر اتصال بالإنترنت، مع وجود خطوط بديلة.
